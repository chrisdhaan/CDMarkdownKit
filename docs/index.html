CDMarkdownKit v3.0.0 Documentation

A pure-Swift, zero-dependency framework for parsing Markdown text into NSAttributedString.

Note: Full API documentation is currently being generated. Complete Jazzy documentation will be available shortly.

Features

  • Parse Markdown to styled NSAttributedString
  • Support for bold, italic, strikethrough, headers, lists, quotes, code blocks
  • Clickable links and automatic URL detection
  • Image support (iOS, macOS, tvOS)
  • Async image loading with async/await
  • Custom Markdown elements
  • Swift 6 concurrency support
  • Available for iOS 15+, macOS 12+, tvOS 15+, watchOS 8+

Quick Example

import CDMarkdownKit

let parser = CDMarkdownParser()
let markdown = "# Hello **World**\n\nThis is *italic* text."
let attributedString = parser.parse(markdown)
label.attributedText = attributedString

Installation

CDMarkdownKit is available via Swift Package Manager, CocoaPods, and Carthage.
